# aexlo studio

[English](README.md) | 日本語

初めてこのリポジトリを使う場合は、[はじめに](../../docs/getting-started.ja.md)で minimal、sdk_noise、interactive を先に試してください。全体像は[サンプル一覧](../README.ja.md)を参照してください。

aexlo を一通り動かして検証するための小さなコンポジターです。`examples/interactive` が 1 つのプラグインのパラメーターを調整するのに対し、studio は実際の After Effects プラグインを他のレイヤーとともにタイムラインに配置します。これにより、レイヤーパラメーター、パスパラメーター、時間とキーフレーム、調整レイヤー、ボタン、パラメーター UI の非表示・無効化といった、周辺のホスト機能が必要な機能も検証できます。

```bash
cargo run -p studio --release              # デモプロジェクトを開く
cargo run -p studio --release -- my.json   # 保存済みのプロジェクトを開く
```

`--release` を使ってください。デバッグビルドでは合成処理が数倍遅くなります。

## 機能

- **レイヤー**：平面（透明にするとジェネレーター用の「ヌル」になります）、画像、シェイプレイヤー（矩形、楕円、星形・多角形、ペンのパス。塗りと線に対応）、テキスト（任意の TTF/OTF/TTC フォントに対応し、システムの日本語フォントにフォールバック）、下にあるすべてのレイヤーをエフェクトで処理する調整レイヤーを使えます。それぞれにトランスフォーム、不透明度、描画モード、イン点・アウト点があります。
- **マスク**：任意のレイヤーにペンやシェイプツールで描画できます。Add、Subtract、Intersect、Lighten、Darken、Difference、None の各モードと、反転、不透明度、ぼかしに対応しています。AE と同様にエフェクト実行前のレイヤーに適用されます。プラグインは Path スイートを通じてマスクを参照でき、`PF_Param_PATH` パラメーターにはそのレイヤーのマスクが提示されます。
- **エフェクト**：同梱のフィクスチャ、またはディスク上の任意のプラグインをレイヤーごとに重ねられます。パラメーターはプラグインの宣言に従ってグループ化され、`PF_UpdateParamUI` による非表示・無効化に従います。ボタンは `PF_Cmd_USER_CHANGED_PARAM` を送信します。レイヤーパラメーターではコンポジション内の任意のレイヤーを選択でき、非表示でもマスクとエフェクトを適用してレンダリングします。エフェクト自身のレイヤーを選択した場合は、そのソースを返します。ポイントパラメーターにはビューアー内にハンドルが表示されます。
- **時間**：すべてのプロパティとエフェクトパラメーターにストップウォッチがあります。キーフレームは Linear、Easy Ease、Hold に対応し、タイムライン上でドラッグして移動し、右クリックで変更できます。エフェクトにはレイヤー時間（`frame - start`）が渡されるため、レイヤーを移動するとエフェクトの時計とキーフレームも一緒に移動します。
- **ビューアー**：ズーム（スクロールまたはピンチ）、パン（Alt を押しながらドラッグ、または中央ボタンでドラッグ）、レイヤーの選択・移動、四隅からの拡大縮小、ノブからの回転、マスクやパスの点・接線の編集（ドラッグ中に Alt を押すと片方の接線だけを移動）、シェイプ要素とエフェクトのポイントのドラッグができます。
- **ファイル**：プロジェクトは JSON として保存します。現在のフレームを PNG、コンポジションを PNG シーケンスとして書き出せます。`PATH` 上に `ffmpeg` がある場合は MP4 としても書き出せます。すべての編集に取り消し・やり直しが対応し、1 回のドラッグは 1 ステップとして扱われます。

## キー操作

| キー | 操作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| ← →（Shift：×10）、Home、End | コマ送り / ジャンプ |
| J / K | 選択中のレイヤーの前 / 次のキーフレーム |
| V、G、Q | 選択、ペン、シェイプツール（Q で切り替え） |
| Enter / Esc | 現在のペンのパスを終了 |
| Delete | 選択中のキーフレーム、マスク、シェイプ、エフェクト、レイヤーを削除 |
| ⌘Z / ⇧⌘Z | 取り消し / やり直し |
| ⌘S / ⇧⌘S / ⌘O | 保存 / 名前を付けて保存 / 開く |
| ⌘D | レイヤーを複製 |
| ⌘] / ⌘[ | レイヤーを上 / 下に移動 |

## レンダリングの仕組み

`engine.rs` は専用スレッドで動作し、すべての `PluginInstance` を所有します。UI はプロジェクトのスナップショットを送り、処理待ちのうち最新のものだけがレンダリングされます。
各レイヤーの処理順は、ソース → マスク → エフェクト（それぞれで `set_input_layer`、`set_time`、パラメーター、`set_mask_paths`、`set_layer_param`、`render_frame`）→ tiny-skia によるトランスフォームとコンポジションへの合成です。内容とマスクが変わらないレイヤーのソースは、フレーム間でキャッシュします。

スクリプトによる検証では、`AEXLO_STUDIO_SCREENSHOT=out.png` を設定すると、最初のフレームが表示された時点でウィンドウを保存して終了します。`AEXLO_STUDIO_SELECT=<n>` を設定すると、先に n 番目のレイヤー（0 が最上段）を選択します。
